# Jayshree Bhunia — Portfolio

One-page portfolio built with React, TypeScript and Vite for full-time Frontend / React / WordPress opportunities.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Before publishing

1. Replace the React project placeholder with public project details when available.
2. Add GitHub and LinkedIn links when available.
3. Keep `public/Jayshree_CV.pdf` updated.

## Deploy to Vercel

Push this repository to GitHub, import the repository into Vercel, and deploy. Vercel should detect Vite automatically.
